# 수동 테스트 체크리스트

브랜치: `feat/localization-and-stock-game`

## 로컬라이제이션

- [ ] 한국어 Discord에서 `/핑`, `/도움말`, `/주식시세`가 한국어 이름으로 표시된다.
- [ ] `/도움말 command:핑`과 `/help command:ping`이 모두 동작한다.
- [ ] 옵션 `채널`, `역할`, `종목`, `수량`, `방식`이 한국어로 표시된다.
- [ ] 영어 환경에서 영어 fallback 명령어와 옵션이 표시된다.

## 주식 게임

- [ ] `/주식시세`에서 4개 종목과 현재가를 확인한다.
- [ ] `/주식매수`의 방식에서 `수량 지정`과 `풀매수`를 선택할 수 있다.
- [ ] 풀매수 시 보유 현금으로 살 수 있는 최대 수량을 매수한다.
- [ ] `/주식매도`의 방식에서 `수량 지정`과 `풀매도`를 선택할 수 있다.
- [ ] 풀매도 시 해당 종목을 전량 매도한다.
- [ ] 잔액·보유 수량 부족 거래가 거부된다.
- [ ] `/내주식`에서 현금, 보유 종목, 총 평가액을 확인한다.
- [ ] 봇 재시작 후 잔액과 보유 주식이 유지된다.
- [ ] 서로 다른 서버에서 동일한 주식 시세가 표시된다.
- [ ] 계정과 보유 주식은 서버별로 분리된다.
